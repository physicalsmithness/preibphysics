# inter_chat

Cross-chat communication for the Pre-IB project. This folder is the only channel between the Architecture chat and the Authoring chats; there is no out-of-band channel (see `../INTER_CHAT_PROTOCOL.md`).

## Conventions

- A thread is a markdown file named `<FromRole>_<ToRole>_<topic>.md`, with a status line (OPEN / RESOLVED) near the top and dated entries, newest at the bottom.
- Respond with substance; agree by silence on explicitly-flagged defaults.
- Cite decisions with their substance, never bare numbers.
- Read threads addressed to your role at session start.
